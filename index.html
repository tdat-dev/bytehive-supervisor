Run it next to ByteHive

Windows and Node 20. Turn on Settings, Remote in ByteHive, then open 127.0.0.1:8599. Without Muse the panel keeps the rule’s own sentence.

git clone https://github.com/tdat-dev/bytehive-supervisor.git
cd bytehive-supervisor
npm install
npm run build
npm start -- --dir D:\my-project
